# Product

## Register

product

## Users

Janus operators administer a production LLM gateway, inspect runtime health,
and manage credentials and provider configuration. They need efficient,
predictable workflows and clear confirmation before security-sensitive changes.

## Product Purpose

Janus Dashboard is the management plane for the Janus gateway. It centralizes
operator configuration and observability while keeping changes explicit,
auditable, and safe. Successful UI work reduces friction and ambiguity without
obscuring system state or changing backend behavior.

## Brand Personality

Precise, quiet, dependable. The interface should feel like a focused operator
console: direct language, visible system state, and no promotional decoration.

## Anti-references

Avoid marketing-site hero patterns, decorative gradients, glass effects,
feature-card grids, unnecessary modals, and visual redesigns that interrupt
established operator workflows. Do not expose editing controls before the
operator expresses intent.

## Design Principles

- Show state first and reveal editing workflows on explicit intent.
- Preserve established navigation and component patterns during targeted polish.
- Make destructive or security-sensitive actions deliberate and reversible
  where possible.
- Verify changes through the real operator workflow at desktop and mobile
  widths.

## Accessibility & Inclusion

Use semantic labels, visible keyboard focus, accessible dialogs, readable text,
and responsive layouts. Respect reduced-motion preferences and do not rely on
color alone to communicate status.
