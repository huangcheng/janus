# Product

## Register

product

## Users

Janus operators manage providers, agent keys, public model routing, gateway nodes, usage, and incident evidence from a desktop admin console. They need predictable controls during routine configuration and urgent troubleshooting.

## Product Purpose

Janus Dashboard is the management plane for the Janus LLM gateway fleet. It centralizes configuration and observability so operators can route models safely, understand traffic and failures, and keep the fleet healthy. Success means completing those tasks without ambiguity, accidental writes, hidden controls, or unreliable interactions.

## Brand Personality

Precise, quiet, expert. The interface should feel like a dependable operations tool: compact without being cramped, familiar without being generic, and direct about consequences.

## Anti-references

Avoid decorative SaaS dashboards, oversized marketing layouts, novelty controls, gratuitous animation, low-contrast text, detached menus, tiny icon-only targets, and dialogs that hide their own actions.

## Design Principles

- Reliability before decoration: every visible control must work with mouse and keyboard.
- Use familiar admin patterns and a consistent component vocabulary.
- Keep operational density while preserving clear hierarchy and readable state.
- Make destructive or configuration-changing actions explicit and reachable.
- Preserve the existing product shell and visual identity; improve components in place.

## Accessibility & Inclusion

Target WCAG AA contrast and keyboard operation. Provide visible focus states, accessible names, sensible hit targets, reduced-motion support, and layouts that remain usable on smaller screens.
