Admin API contract

JSON API consumed by the React SPA. Served by the admin listener under /admin/api — never mixed with the data plane.

Auth & conventions

Session
cookie janus_admin_session (HttpOnly · SameSite=Strict · 12 h)
CSRF
mutations send header X-Janus-CSRF: <token> from GET /session
Auth errors
401 → SPA redirects to /admin/login; 403 = bad CSRF; 429 = login lockout
Errors
uniform body, mapped to toast + inline field errors
Mutations
validate → write → bump config generation → catalog hot-swaps; every call audited
// 4xx/5xx body
{ "error": { "code": "duplicate_name", "message": "provider name exists", "field": "name" } }

Session

POST/admin/api/sessionlogin {password} → sets cookie, returns {csrf, expires_at}
GET/admin/api/sessioncurrent session (401 when logged out) → {csrf, expires_at}
DEL/admin/api/sessionlogout, clears cookie

Providers & provider keys

GET/admin/api/providerslist with key metadata (never secrets)
POST/admin/api/providerscreate {name, base_url, protocol}
POST/admin/api/providers/:id/disable · /enabletoggle, immediate
DEL/admin/api/providers/:iddelete with keys + routes (confirm modal)
POST/admin/api/providers/:id/keysadd key {secret, weight, key_id?} → encrypted at rest
POST/admin/api/provider-keys/:id/disable · /enabletoggle key
DEL/admin/api/provider-keys/:idremove key (confirm modal)

Models & routes

GET/admin/api/modelsmodels with nested routes
POST/admin/api/modelscreate {name}
POST/admin/api/models/:id/disable · /enabletoggle model
POST/admin/api/models/:id/routescreate route {provider_id, upstream_model_id?, weight, priority}
POST/admin/api/models/:id/routes/:pid/disable · /enabletoggle route
DEL/admin/api/models/:id/routes/:pidremove route (confirm modal)

Agent keys

GET/admin/api/keysprefix, grants, created_at, enabled
POST/admin/api/keyscreate {model_ids: [..]} → returns plaintext key exactly once
POST/admin/api/keys/:id/disable · /enabletoggle key
DEL/admin/api/keys/:idrevoke permanently (confirm modal)
