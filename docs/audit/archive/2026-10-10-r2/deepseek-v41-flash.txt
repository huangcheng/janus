1. **Verdict: GO WITH FIXES** — the rev-2 folds are mostly coherent, but capacity semantics, the health comparison, and gate 13.5 still contradict each other.

2. **Critical risks**
- **Health demotion is an Erlang trap.** `observed_ewma_ms > demote_ms` with `observed = unknown` (atom) is ALWAYS true (atom > number; `infinity < unknown`). New workers (<3 samples) get demoted, violating A.4/B.4. Needs `is_number(observed) andalso observed > demote_ms` or store `unknown := infinity`.
- **Gate 13.5 contradicts tier 3.** Tier 3 says all-at-capacity ⇒ ignore filter, dispatch anyway + `sched_capacity_exhausted_total`. 13.5 asserts `sched_dispatch_local_total{reason=capacity} ≥ 1` and `worker_total = 1`. With capacity=1 and two jobs, tier 3 dispatches both to the worker (worker_total=2). One of the two is stale.
- **Capacity has two owners.** B.3 (pure `select_v2`) needs live reservation counts, but Part C puts reserve-then-rollback in `pick`, and snapshot `inflight` is declared "sort hint only". `select_v2(snapshot, opts)` cannot see the counter — either tier 3 isn't pure, or it uses the hint it disclaims.
- **Affinity vs Part 0.6.** Affinity is "absolute… ignoring capacity", so the live counter exceeds capacity while 0.6 calls it "the truth". Soft-cap needs to be stated or reservation suppressed under pin.
- **Lock-free drain staleness.** Snapshot is a hint; a node draining between publish and pick still receives a job (v1's synchronous select could not). No re-check/lease specified.

3. **Contradictions / stale claims**
- `JANUS_SCHED_GEO=0` gating of tier 5 vs legacy `region_tag` staying v1-active — v1-equivalence eunit breaks if region_tag is gated.
- "env-config only" vs Part C "persistent_term … hot-reload" (env doesn't reload).
- 13.4b "usage rows carry no probe marker" — there is no marker column; assert row-count delta instead.

4. **Missing first-ship requirements**
- Worker region vocabulary is unconstrained; an operator using `us-west` never matches mapping output `us` (silent auto-geo miss).

- Probe spend can starve entitlement probes (shared per-provider budget).
- Re-validation of drain/liveness at reservation time.
