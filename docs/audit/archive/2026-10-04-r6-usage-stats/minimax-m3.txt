**Critical risks:**

- **`trim_tail` is O(N²)**: each chunk arrival folds the full chunk list. Memory is bounded (chunk-list, not 16KB binary concat), but per-chunk iteration cost grows with chunk count. Comment overstates the fix.
- **`record(Bad)` (no status) bypasses mailbox guard**: floods of `#{}` casts skip the queue-length check and saturate the mailbox. Round-3 back-pressure is partial.
- **`rewrite_pg` is naive**: rewrites `?` inside `'…'` literals. Current SQL has none; any future `LIKE 'a?b'` is silently mangled to `'$N'…'`.
- **avg vs p95 empty semantics inconsistent**: `totals` returns `avg_latency_ms => 0` (COALESCE) but `p95_latency_ms => null` for the same empty window. Misleads the UI.
