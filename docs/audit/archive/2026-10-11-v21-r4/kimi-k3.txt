## 1. Verdict
**GO WITH FIXES** — rev-3 folds are landed and coherent in 20/21 spots, but F4's body was never actually rewritten (stale v2 eviction text contradicting C.1), and B.2/C.2 carry two smaller internal contradictions.

## 2. Critical risks
- **F4 body is stale.** Part 0.2 F4 still reads "the /metrics rendering caps label sets exactly like /stats/sched does (64-entry budget, **evicted label sets removed from the registry** — the v2 rule)". C.1 mandates counters NEVER evicted (reject-new-into-overflow) and gauges deterministic without eviction. The preamble claims F4 was rewritten; it wasn't. An implementer reading Part 0 first will build the wrong registry semantics — this is exactly the incident class the dirty-tree guard (C.4) exists to prevent, now in spec form.
- **C.2 worker-side rendering path doesn't exist.** "Each node renders its OWN `janus_sched_dist_*` counters on its own /stats/sched" + final line "Exposed through `sched_stats/0` (additive) and C.1 rendering" — but `janus_worker_pool:sched_stats/0` is master-only; workers run no pool. The worker's admin listener needs a direct `janus_dist_monitor:stats/0` read, and C.1's "reads `sched_stats/0` ONCE per scrape" must not crash/omit on workers. Unspecified.

## 3. Contradictions or stale claims
- **B.2 vs A.3 on "ONE canonical number".** B.2: "the snapshot builder, the sort key, /stats/sched `rtt_ms_avg`, and the /metrics gauge ALL read the row's Ewma". But `rtt_ms_avg` is per-NODE (mean of unexpired per-provider cells per A.3) — for a 2-provider node it is no row's Ewma. A.3's "ONE canonical RTT family… display-only aggregation" wording is correct; B.2's sentence predates it. Fix B.2: sort key + gauge read the row Ewma; `rtt_ms_avg` is the A.3 mean.
- **"Bit-for-bit v1 ordering" overclaims.** With the sort reading `sched_reserve` LIVE, runtime ordering under concurrent load can diverge from v2's flush-bounded hint (intended — "FRESHER"). The pure-function equivalence eunit still holds; scope the invariant wording to the pure contract, not runtime traces.
