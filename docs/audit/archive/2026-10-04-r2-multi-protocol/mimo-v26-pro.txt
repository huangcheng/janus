## 2. Critical risks
- **Tool fidelity:** Anthropic requires `tool_result` as a user content block *immediately* after `tool_use`; `tool_choice` (auto/any/tool/none vs none/required/auto/function), parallel-tool flags, and `strict` have no clean mapping. "Basic shapes" is undefined 鈥?the boundary must be a fail-closed allowlist, or fields vanish silently.
- **Silent drops beyond tools:** `system`鈫抰op-level `system`, `stop`鈫抈stop_sequences`, **`max_tokens` required by Anthropic but optional in OpenAI** (must synthesize), `n>1`, `response_format`, `logprobs`, `seed`, `stream_options.include_usage`, Responses `store`/`previous_response_id`/`background`/reasoning items. Usage (`input/output_tokens`) and `stop_reason`鈫擿finish_reason` (`tool_use`鈫?`tool_calls`) must be translated back or clients break.
- **SSE/streaming:** passthrough is fine only if the handler drains gun into Cowboy chunked with backpressure and `gun:stop` on client disconnect; with HTTP/2 upstreams, per-stream teardown differs. Cooldown can only key off the status line 鈥?an error event after `200` can't flip status; define that contract.
- **Auth confusion:** on `/v1/messages`, if both `Authorization: Bearer` and `x-api-key` are present (different keys) there's no precedence rule. Worse, if inbound `x-api-key`/`anthropic-version` are forwarded upstream, the **agent key leaks** or the provider sees the wrong key. Header filtering must strip-and-inject.
- **Auto-router:** `maps:get(protocol, Provider)` crashes (500) on rows lacking the key; auto + `stream:true` + translate must fail fast to 400 *before* tier pick/cooldown.
- **Cooldown/error contracts:** local `translate_unsupported` 400s must not count as provider failures; error body must match client protocol (Anthropic `{"type":"error",...}` vs OpenAI `{"error":{...}}`).
