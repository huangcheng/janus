**1. Verdict:** GO WITH FIXES — phase structure is sound, but unblocking the blocked predicate without failover-reset, usage-injection, and real fixtures first will break the gate and ship half-faithful translations.

**2. Critical risks**
- **Failover × accumulator:** the retry loop reissues requests with per-attempt usage rows, but nothing resets `sse_st`'s tool-call accumulator on retry — attempt 2's deltas append to attempt 1's partial JSON, silently corrupting arguments. Also undefined: translated streams can only retry pre-first-client-byte; plan never states this window.
- **Usage semantics:** chat upstreams emit usage only if `stream_options.include_usage` was sent; anthropic emits in `message_start`/`message_delta`. Translation must inject include_usage upstream and pick a deterministic emit point per target. E2E asserting "usage rows" but not counts lets zero-token rows pass.
- **Missing mapping tables:** `end_turn/tool_use/max_tokens/stop_sequence` ↔ `stop/tool_calls/length/content_filter`; responses `incomplete_details`, `response.failed`/`error` events — mid-stream error translation entirely unspecified.
- **Fixture ordering:** 1.1/1.2 eunit will inevitably use hand-invented frames while real captures are deferred to 3.3 — violates the AGENTS.md fixture-realism rule the plan itself cites.
- **Responses grammar scope:** 2.2 "extend + harden" hides a large grammar (`function_call_output`, reasoning items with `encrypted_content`, `text.format` structured output, `tool_choice`, `parallel_tool_calls`). Needs explicit strip+`X-Janus-Dropped` policy, not silent loss.
- **Hot path:** per-delta binary acc copies; 3.4 load test lands only after phases 1–2 state changes shipped.

**3. Contradictions / stale claims**
- 1.3/2.3 flip `stream_translate_blocked` but never enumerate the existing eunit (of the 123) and gate steps (E.5/E.6 family) asserting blocked-400 behavior — they fail after unblock.
- Header claims image parts "pass through translate on the REQUEST side already," yet 1.2 still tests the request path; state what actually remains.
- After Phase 2, `prefer_proto` fires only for `n>1`; near-dead substrate, no retirement note.

Ship `docs/protocol-mapping.md` (events, terminators, usage placement, drops per pair) as the reviewable artifact before code.
