**Verdict: GO WITH FIXES** — the four slices are sound and correctly scoped, but the Anthropic client envelope details, run-time (not build-time) CRLF handling, and the deploy-pause/migration hazard must be patched before implementation.

**Critical risks**
- *Anthropic client envelope:* §4.1.3 lists event names but omits required payloads — `message_start.message` (id/type/role/model/stop_reason/usage with `input_tokens`/`output_tokens`), `content_block_start.content_block` object (`{"type":"text","text":""}` / `thinking`), `message_delta.message.usage` (cumulative). Claude Code SDK rejects partial envelopes.
- *n>1:* streams with multiple choices unstated; must be rejected or asserted single-choice.
- *`sse_events/2` contract:* multi-line `data:` joining and `:`-comment keepalives unspecified — real Anthropic sends periodic junk pings; missing comment-skip can poison the buffer.
- *Cowboy idle:* zero-byte OpenAI thinking >300s will 502; spec accepts this but documents no keepalive — at least emit periodic `: ping` comments on the client face while waiting.
- *Deploy halt vs migrations:* halting after leader migration leaves followers on old binaries over a migrated Postgres → boot crash loop. Need the "migrations backward-compatible one version" invariant, or a follower gate before leader migrate.
- *Counter aggregation:* dashboard Nodes table semantics (per-node vs cluster sum) undefined.

**Contradictions / stale claims**
- TF-6.8 asserts a `stream=1` usage column — verify the column exists in PG schema/`janus_usage` before committing the flow.
- §2/4.1.1 quote `dispatch/7` behavior — re-verify against current `janus_http_proxy.erl` (round-1 refactors may have shifted it).

**Missing requirements**
- Behavior when `message_start` JSON lacks `usage.input_tokens` (Anthropic streams sometimes omit) — must default undefined, not crash.
- `include_usage` injection must fire only on translating streams, not same-protocol native passthrough (double-injection risk with the existing helper).
- Streaming disconnect → usage lost: state explicitly that tokens may be null.
- Ops semantics: `track(400)` for post-200 translate errors means `requests_failed` disagrees with wire status — document for the Nodes UI.

**Architecture notes**
- The `try … after` + `janus_stats_counted` flag is correct, but set the flag *immediately* after `inc_total()` — no crash window with total-but-unflagged.
- `finalize_sse` idempotence is the load-bearing invariant; eunit must call it twice (error branch after `[DONE]`) and assert exactly one terminator.
- persistent_term atomics in `janus_http_app` pre-listener init is the right pattern; `if ref missing emit 0` matches AGENTS.md.
- Cowboy `stream_body/3` + gun cancel on disconnect is correct; don't await `collect_drain`.

**Top 5 concrete edits**
1. Extend §4.1.3 tables with full Anthropic envelopes + explicit single-choice/n=1 rule (reject n>1).
2. Move CRLF handling into the `docker run` command (conditional `dos2unix` before `fmt --check`); image RUN can't see mounted bytes.
3. Add the one-version migration-compat invariant to AGENTS.md/SPEC before Slice D ships.
4. Patch dashboard SPEC §2.4 + `nodes.tsx` to define per-node vs cluster aggregation as part of Slice B.
5. Add to `sse_events/2`: multi-line `data:` join, `:`-comment skip, missing-usage fallback; add eunit cases for each.
