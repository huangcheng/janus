## 1. Verdict
GO WITH FIXES — the slicing and deferrals are sound, but the SSE state machine, counter guard, and streaming headers contain concrete contract bugs that would ship broken.

## 2. Critical risks
- **`translate_sse` return type is wrong.** `skip` carries no `#sse_st{}`, yet the mapping mutates state on skipped events (`content_block_start` records `block_kind`, `message_start` stashes `msg_id`/`in_tokens`, usage chunks stash tokens). Must be `{skip, St}` or those fields are lost → no thinking blocks, no usage.
- **Missing streaming headers.** No `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `X-Accel-Buffering: no`. Caddy sits in front (spec §1); without flush/no-buffer, translated streams stall.
- **Counter invariant breaks.** Table says 401/400-before-`do_proxy` → 0/0, but bump rule is "`track` Status≥400 → failed". If those paths call `track(401)`, `failed > total`. `janus_stats_counted` guard must cover `track`, not just the `after` crash path.
- **Anthropic `message_start` has no input usage.** Provider Chat yields usage only at end; Anthropic clients expect `usage.input_tokens` in `message_start`. Emit 0/synthesized or document.
- **Block index undefined.** `#sse_st{}` has one `block`/`block_kind`; text→thinking→text transitions need a monotonic index counter, else `content_block_delta` indices collide.

## 3. Contradictions / stale claims
- §4.1.4 "Idle no bytes → idle_timeout 300_000 → 502" contradicts the baseline note that `idle_timeout` is a between-requests keepalive timer, not a mid-response watchdog. Cowboy won't kill a silent in-flight SSE. Define the real detection.
- `/stats` called "read-only admin" but Slice D introduces `JANUS_STATS_TOKEN` bearer auth — a listener behavior change absent from the §7 touch map.
- "compile already in the image" is false for the Windows `-v F:/Janus:/app` mount (host source + empty named volume → runtime recompile/fetch).
- `.gitattributes`/`core.autocrlf=false` is a local git config, not repo-enforced; use `text eol=lf` entries or `fmt --check` stays flaky.

## 4. Missing requirements
- Reverse stop-reason defaults (`content_filter`, `function_call`; Anthropic `refusal`/`pause_turn`).
- `stream_options.include_usage` injection may 400 on strict OpenAI-compatible upstreams — needs tolerance/fallback.
- Disconnect detection mechanism (`cowboy_req:stream_body` `{error,closed}` vs process exit) and gun cancel ordering.
- eunit fixtures: `\r\n` vs `\n`, split across `event:`/`data:` boundary, `[DONE]`-less providers.
- Leader generation source for the two-consecutive-poll compare (captured after migration, not re-read each poll).

## 5. Architecture notes
- Handler owns `#sse_st{}` — good; keep usage capture on provider bytes via `capture_usage_chunk` (native shape), but note Anthropic usage is split `message_start`+`message_delta`, so "one row" assembly must wait for `message_stop`.
- `persistent_term` atomics boot order matches `janus_usage`; fine. janus-auto inner judge/target must bypass `inc_total` (enforce one call).
- Dual-repo pairing is correctly flagged; TEST-FLOWS must own TF-6.8/6.8b.

## 6. Top 5 edits
1. Change contract to `translate_sse(...) -> {ok,Frames,St} | {skip,St} | {error,...}`.
2. Add SSE response headers + Caddy flush/no-buffer note.
3. Extend `janus_stats_counted` guard to `track`; add invariant test.
4. Define block-index counter and `message_start` usage synthesis.
5. Resolve idle_timeout claim; add `/stats` token auth to touch map.
