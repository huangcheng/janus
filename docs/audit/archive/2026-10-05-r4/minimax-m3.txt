**Critical risks:**

1. **Counter bump table self-contradicts** (§4.2). "Enter `do_proxy` after successful JSON map" implies model check is inside; but row "missing model **before** `do_proxy` | 0 | 0" says neither increments. TF-6.1 wants unknown-model to increment both. Pick one and bind it.

2. **Chat→Anthropic `input_tokens` is stuck at 0** (§4.1.3). `message_start` writes `usage: {input_tokens: In or 0, output_tokens: 0}`, but `prompt_tokens` arrives on the empty-choices usage chunk **after** the first content delta. §10's "do not rewrite message_start" is the **opposite** direction (provider Anthropic → client Chat). Either emit a corrective `message_delta.usage` patch when that chunk lands, or document the always-0 behavior in the README — Anthropic clients keying cost off `message_start.usage.input_tokens` will see 0 every time.

3. **Deploy wait deadlocks on no-op config ship** (§4.4). If the config diff is empty, generation never bumps; `gen0 == captured leader gen`, so `> gen0 OR == captured` fails forever on every follower. Add a "config diff empty ⇒ skip generation wait" branch before the poll loop.
