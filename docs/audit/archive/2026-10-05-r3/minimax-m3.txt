**1. Verdict:** GO WITH FIXES — sound spec; tighten gun cancel, janus-auto counter semantics, and one Slice D code-only ambiguity.

**2. Critical risks:**
- **Mid-stream gun cancel race.** `finalize_sse(disconnect)` and gun cancel both gated by `terminal_sent`; if `stream_body` returns `{error, closed}` while gun cancel is in flight, two cancels may double-close the gun stream. Mandate single owner (handler process) and idempotent gun cancel.
- **`idle_timeout` is per-request, not per-byte.** Spec distinguishes correctly; add E2E fixture: idle-counter at 0, T=300s upstream first-byte still succeeds.
- **Anthropic `message_delta` carries `usage.output_tokens` + `delta.stop_reason` together.** Spec emits "finish chunk → usage chunk → `[DONE]`", but if `output_tokens` is already in `message_delta`, the second chunk duplicates tokens. Pin: if `message_delta.usage` present, suppress post-finish usage chunk.
- **janus-auto counters.** "=1 call" but path internally invokes judge + target. Judge 500 → +1 failed; target never invoked. Pin: inner judge failure = +1 failed **iff** client-visible status ≥ 400; if janus-auto short-circuits without 4xx/5xx, +0 failed.
- **`include_usage` injection scope.** "Translating Chat-upstream" is ambiguous. Specify: inject only when provider=OpenAI Chat **and** client=Anthropic Messages; never on native Chat↔Chat or Chat→Responses.
- **Named volume cross-OTP.** `janus-ebin-otp27` persists `_build`; OTP bump leaves stale beam files. Document: recreate the named volume on OTP version change.
