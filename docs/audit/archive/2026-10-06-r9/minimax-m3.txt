## Audit

### 1. Verdict
**GO WITH FIXES** — §10 internally contradicts itself for native Chat→Chat streaming; the two relevant closed decisions do not scope each other.

### 2. Critical risks
- **Inner janus-auto usage rows**: inner `track` writes a usage row in addition to outer — 2 rows per janus-auto client call; audit vs count unclear.
- **Missing `stats_url` per node**: §4.4 handles empty `JANUS_STATS_TOKEN` (#6) but not null `stats_url` — deploy crashes.
- **Stale captured leader gen**: §4.4 #1 says "do not re-read every poll"; a concurrent ship bumps leader gen mid-wait, captured value is stale.
- **Post-terminal disconnect**: handler exits after `[DONE]`/`message_stop`; cannot detect later disconnect. Spec records 502 unconditionally.

### 3. Contradictions or stale claims
- §10: "Chat-face `created` is always the gateway clock" vs §10: "Native bytes unchanged except optional `x-accel-buffering: no`" — for native Chat→Chat, both apply and contradict.
- §4.1.4 "Native path: ... do not otherwise change bytes" echoes the second §10 decision.

### 4. Missing requirements
- **§4.2**: explicit inner janus-auto `track` usage-row semantics (audit row vs suppress for 1-per-client-call).
- **§4.4**: halt condition for missing `stats_url` per node.
- **§4.1.4**: post-terminal disconnect — handler has exited; no further track possible.
- **§4.4**: bound captured leader gen staleness — re-read per poll or wall-clock ceiling.
- **§4.3**: CRLF check in CI for mounted source (spec mentions `.gitattributes` only).

### 5. Architecture/design notes
- Handler-owned `#sse_st{}` with single leftover owner is clean.
- `sse_events → fold translate_sse → write immediately` is the correct drain shape; cap on `Buffer+Chunk` AND on any complete `data:` line is sound.
- Persistent_term atomics reset only on app init (not hot reload) — correct for stable counters.
- Dual-repo paired PRs correctly scoped (A→TEST-FLOWS, D→deploy_prod.sh).
- Inner janus-auto `put/erase` around inner `do_proxy` is correct.

### 6. Top 5 concrete edits
1. **§10**: resolve the `created`/native-bytes contradiction — either scope "Chat-face `created` is always the gateway clock" to translate only, or amend "Native bytes unchanged" to exclude `created`.
2. **§4.4**: add halt condition for missing `stats_url` per node (analogous to #6).
3. **§4.2**: explicitly state inner janus-auto `track` writes an additional usage row (audit trail).
4. **§4.1.4**: clarify post-terminal disconnect — handler exits after terminator; no further track.
5. **§4.4**: bound captured leader gen staleness — re-read at each poll iteration or add wall-clock ceiling.
