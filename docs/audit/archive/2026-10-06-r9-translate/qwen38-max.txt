**1. Verdict**

GO WITH FIXES — rev 9 is structurally sound after 8 audit rounds; five concrete defects need fixing before implementation, none invalidate the phase skeleton.

**2. Critical risks**

- **C5 full-accumulate-emit-at-close kills TTFT.** Interleaved chat streams buffer ALL text until close points; worst case time-to-last-token. Anthropic legally allows multiple sequential text blocks — text arriving before/mid tool deltas can stream until interleaving actually forces deferral. As written, this also imposes responses-target full-object requirements on Phase 1 chat↔anthropic.
- **C4(b) only covers headers-flushed.** All-attempts-fail *pre-any-byte* (1.4a's mode) should return a proper HTTP 4xx/5xx, not 200+error-frame. Plan never distinguishes; entitlement-row semantics for zero-progress failures underspecified.
- **Knob→LB wiring has no implementation task.** 1.9 asserts "knob ON prefers native route for lossy pair," but `pick_route` only accepts caller-supplied `prefer_proto`; someone must read the new persistent_term knob. Asserted, never assigned.
- **1.0 truncation fixture risks hand-invention.** Real providers rarely emit capturable mid-stream truncations; it must derive from 1.4a fault-injection replaying captured transcripts, else it violates the very fixture-realism rule it cites.
- **1.4b scope creep:** client-abort cleanup (cowboy/gun lifecycle) is not a pure state-machine property; eunit here risks fake coverage of an E2E-only behavior.
