**1. Verdict:** GO WITH FIXES — R7 decisions are internally sound; remaining issues are a finalization durability gap, one stale gate contradiction, and three unhandled edges.

**2. Critical risks**
- **Terminal-finalization durability:** M1.1/M3.3 CAS is a single-statement `UPDATE video_jobs ... WHERE status='pending'`, but the one usage_events INSERT is a separate step. Winner crash between CAS-commit and insert = permanent usage loss (row no longer pending, nothing retries). Must be one transaction on both dialects.
- **Budget arithmetic:** per-attempt gun budget (270s) vs the total pre-accept wall-clock knob is never reconciled — the shared loop must use `min(attempt_budget, remaining_total)` or the knob is decorative and two slow attempts exceed 300s idle.
- **ASR admission** keys on `content-length` at header time; chunked transfer-encoding uploads bypass it. Decide: reject chunked, or hold slot + stream-cap.
- **Buffered-reply memory:** 64MiB image/video JSON cap × unbounded concurrency has no admission control (only ASR has slots). Slow-accept fan-out can OOM a node.
- Sync holds send **zero bytes for up to 270s**; any client proxy with 60s read-timeout aborts. Sound given lazy emission, but needs explicit client-guidance doc, not silence.
