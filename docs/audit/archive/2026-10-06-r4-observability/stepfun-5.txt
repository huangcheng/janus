**2. Critical risks**
- **Label cardinality:** contained — closed enums + operator provider names only; provider orphaning after delete documented.
- **Hot-path cost:** ~16 `update_counter` + `whereis` pairs per request, `write_concurrency`, whole-body try/catch, zero formatting — acceptable.
- **Exposition format:** golden tests pin HELP/TYPE-once, zero-filled numeric ladder, `+Inf` last, escaping incl. NUL. Caveat: `float_to_binary(F,[short])` can emit `1.0e7` (legal; say so in README).
- **Auth reuse:** verbatim extraction, identical token/loopback semantics, Caddy warning present.
- **Histogram sanity:** correct, but the count/+Inf ordering comment overstates — a scrape can still transiently see count > an older bucket. Inherent, harmless, mislabeled.
- **Request-id hygiene:** `[A-Za-z0-9-_]{1,128}` blocks CRLF injection; lowercase hex; "untrusted, non-unique" documented.
- **Migration:** dual-dialect identical, ledger dedupe, index-lock + CONCURRENTLY caveat sound.
- **Multi-node:** per-node jobs with separate token files; sum counters, never LB gauges.

- Renderer pure, registry-driven, deterministic; `tab2list` non-atomicity reads only as transient histogram skew — acceptable.
- Hooks (`track/3` + `reply_err/6` with `janus_req_counted`) cover proxy paths; models post-auth errors uncounted by design, documented.
