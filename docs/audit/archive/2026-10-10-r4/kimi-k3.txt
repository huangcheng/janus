**2. Critical risks**
- **Probe target rule vs 13.4b (blocking).** Part 0.2 restricts probe targets to "dispatchable workers × **geo-known providers** with absent/expired RTT." Gate 13.4b enables only `JANUS_SCHED_PROBE=1` + `PROBE_FORCE=1`; geo is off, so every provider geo is `unknown`, the target set is empty, and `probe_total ≥ 1` is unsatisfiable. - **`{sched, 2, {load, _}}` message class.** Part 0.10/A.3 say "cast" but claim the old pool's **`handle_info` catch-all** drops it. A `gen_server:cast` lands in `handle_cast`; a raw `!` lands in `handle_info`. Old-master tolerance depends on which — pin the actual send mechanism and the matching catch-all, and eunit that exact path (the rev-4 "load-cast shape eunit" only covers the shape, not the delivery class).

If fast errors feed the EWMA, a sick worker erroring quickly looks healthy; if they don't, an error-heavy worker starves its own sample count and is never demoted. State the rule.
