**1. Verdict** — GO WITH FIXES — sound approach, but CRLF on the Windows bind mount, generation-wait policy, mid-stream error shapes, and SSE tool-call deltas need resolution before code.

**2. Critical risks**

- **CRLF on Windows bind mount**: `sh -c './rebar3 fmt --check …'` against a CRLF tree breaks shell scripts and confuses some eunit readers. Add `dos2unix` (or `sed -i 's/\r$//'`) to the test image, or have it copy source in (CI path) and use the bind mount only as cache.
- **Generation-wait has no timeout / dead-follower policy**: "timeout + fail" with no numbers blocks deploy on a single dead node. Specify per-node timeout (e.g. 5 min), max retries, and "skip-after-N" semantics for unreachable followers.
- **Mid-stream error frame shape unspecified**: Chat SSE needs `{"choices":[{"finish_reason":"error"}]}` + `[DONE]`; Anthropic SSE needs `{"type":"error",…}`. Per-protocol shapes must be a table.
- **Slow-client backpressure + client-disconnect handling**: Cowboy chunked response has no native backpressure; gun keeps reading upstream until idle. Bound provider→client buffer (256 KB) with 502 on overrun; cancel gun stream on transport close instead of waiting on idle timeout.
- **Counter via `track/3` is fragile**: `track/3` already handles usage + cooldown + status; mixing request-counter semantics risks double-counting an upstream 5xx whose `usage_event_status=200` was already written. Add dedicated `inc_requests_total/0` / `inc_failed/0` callsites in `janus_http_proxy.erl`, decoupled from `track/3`.
- **Tool-use SSE mapping pair ambiguous**: non-stream returns a full translated body; SSE needs delta-level state per tool-call index across `content_block_*` events. Add an explicit event-mapping table or scope tool-use out of Phase 1 A.

**3. Contradictions / stale claims** — none material. `capture_usage_chunk` on provider bytes is the right call; do not re-parse translated client SSE. Exclusions of `openai_responses`, vision, and quotas are correct. `openai_chat ↔ anthropic_messages` is the only pair in scope — keep that contract strict.

- Counter classification table: 401 auth, 400 bad JSON, 404 unknown model, 502 upstream, 500 crash → which increments `requests_failed`?
- Deploy generation timeout value + per-node skip-after-N.
- TF-6.8 fixture: Anthropic `thinking_delta` + `tool_use` deltas → Chat `reasoning_content` + `tool_calls`, including a split frame across two drain callbacks.
