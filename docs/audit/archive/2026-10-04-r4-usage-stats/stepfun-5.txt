**Verdict:** GO WITH FIXES — A1–A10 resolves most v1 findings on paper, but ships one fatal fix-vs-task divergence (migration), a NULL-semantics hole in the proxy, and a Postgres backend that is never once executed.

**Critical risks**
- **Migration (blocking):** Task 1 still contains the pre-A1 DDL. An implementer following task order builds `usage_events` without `stream`, then A3's 11-column insert fails on every flush. `CREATE TABLE IF NOT EXISTS` silently no-ops if the old DDL was already applied — no `ALTER` path exists. A1 must physically replace Task 1, not sit beside it.
- **Dual-DB SQL:** never exercised against Postgres. `percentile_disc(0.95)` vs SQLite `OFFSET trunc(Count*0.95)-1` diverge at n=101 (96th vs 95th value); A5's "nearest-rank equivalence" claim is wrong. Task 4's `bucket_expr` omits `AT TIME ZONE 'UTC'` (`to_timestamp` yields timestamptz → session-TZ drift). Unverified: epgsql affected-row shape (A4's own hedge has no scheduled fallback), `||` cast, `numeric`-as-binary decode, `PRAGMA foreign_keys` state.
- **gen_server:** `q/2` has no try/catch; if `janus_db_conn:query` exits, the writer dies and the whole in-flight buffer + 1s window is lost on restart. `dropped` is write-only — unobservable except logs.
- **Data plane:** tail reassembly copies ≤16KB per SSE chunk (O(stream size)) — acceptable, but `track/3` defaults tokens to **0**, defeating A1's "NULL = not reported"; every no-usage event becomes a real zero.
- **Hot path:** total added cost (2 PD reads/writes + one cast + 20KB parse per stream) is fine; the stream-vs-non-stream p95 blend stands — the new `stream` column is not used to segment it.
