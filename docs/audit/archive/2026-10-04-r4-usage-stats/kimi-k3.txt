## 1. Verdict
**GO WITH FIXES** — the v1 fixes genuinely close the flagged SSE/parser/sweep/p95 holes, but A5's provider-key SQL collides with `rewrite_pg`, and the stream/non-stream latency split is recorded yet never read.

## 2. Critical risks
- **A5 × `rewrite_pg` collision (Postgres breakage):** `breakdown_dim(provider_key)` embeds the literal `'?'` in `COALESCE(CAST(pk.id AS TEXT), '?')`. The Task 3 `rewrite_pg/1` blindly rewrites every `?` → `$N`, corrupting the literal and shifting placeholder numbering → param-count mismatch on Postgres. Highest-severity new bug, introduced by the fix itself.
- **Latency mixing unresolved on the read path:** A1/A6 add the `stream` column and A9 relabels "p95 end-to-end", but no query (`totals`, `p95`, `series`, `recent` filters) selects or splits on `stream`. The original mixing complaint persists in every displayed number.
- **SQLite p95 off-by-one:** `Offset = max(0, trunc(Count*0.95) - 1)` diverges from nearest-rank (`ceil(0.95N)-1`); e.g. N=10 → rank 9 instead of 10. Small but contradicts the "same semantics as percentile_disc" claim.
- **Protocol atom binding:** events carry `protocol => openai_chat` (atom) into a TEXT column; esqlite tolerates atoms, epgsql text encoding of bare atoms is unverified — a silent flush-error source on Postgres.
- **Retry/failover accounting unspecified:** if the proxy retries another provider after a 5xx, each attempt emits an event, inflating requests/errors per client call. Plan never states attempt-vs-request semantics.
- **Drop policy mislabeled:** A3 says "drop-oldest" but drops the incoming (newest) event; `dropped` counter is never exposed via any getter or summary field.

## 3. Contradictions / stale claims
- Task 3 export list says `recent/1`; A5 makes it `recent/2` — export/`-spec` unsynced.
- Task 8 `UsageSummary` type lacks `by_provider_key` (A8 adds it to the API); `p95_latency_ms: number` vs A5's new `null`-on-empty.
- Self-review still claims "insert result ignored… log line on flush error is a fine follow-up" — directly contradicted by A3 (logged, counted, capped).
