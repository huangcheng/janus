**Verdict:** GO WITH FIXES — matrix + failover design is sound; the five edits below close the live correctness gaps.

**Critical risks**

- **Probe silent fail-open on truncation**: 1000-call/10-min cap routinely hit on 262-listing providers; cap cuts the unbound tail alphabetically → unbound models stay `unknown`=eligible=picked blind, no alert path.
- **Deny-regex false positives on transient copy**: regex matches `"not activated|未开通|not entitled|product.*not.*activate"`; provider maintenance copy benches a good key for deny's 24h TTL.
- **TTFB assumption unstated**: 240s ceiling = idle_timeout − TTFB only if gun TTFB ≤ 60s; the SPEC never asserts the gateway's actual gun config, so the ceiling is not derived — only asserted.
- **input_shape healing loops forever**: same `max_tokens=1`+"hi" probe re-hits input_shape 400 every 1h heal → permanent `ok+input_shape` wart, no client gating, no auto-promote.
- **Crash-marking durability gap**: usage rows sit in janus_usage's 1s/100-row buffer; a crash before flush loses both row and `request_ref` — defeats the 5-min backfill.
- **Key-rotation grace window**: bad paste between secret-update (rows cleared) and probe-complete burns 401-retry cycles on every request; LB needs a 401-broken-key shortcut.
- **Retry storms (v1-acceptable)**: per-key cooling suffices; no pool-level breaker — explicit accept, document.
- **Streaming first-byte / matrix reload races / balance starvation**: covered (snapshot-once-at-dispatch, 1h balance TTL, probe-driven heal, test 17/18).

**Contradictions / stale claims**

- "Single-flight per provider (in-process lock)" vs later "there is no in-process lock" — pick advisory-only.
- "ok valid 7 days" vs "ok re-probed after 3d (1h if input_shape)" — gateway never ships ok rows; first is misleading.
- Ceiling math "idle_timeout − TTFB = 240s" without pinning TTFB at 60s.

**Missing requirements**

- Erlang classifier default when `entitlement_codes` carrier is empty (cold boot / new provider): regex fallback + warning + counter.
- Wall-time cap vs bound-set priority: state which cap may cut before bound coverage completes (call-count cap alphabetical, wall-time cap is stop-the-clock).

**Architecture / design notes**

- Snapshot-once-at-dispatch + ETS atomic rebuild is correct; per-attempt reads stay lock-free.
- Billing aggregation `WHERE is_terminal=true` must weight token totals by attempt, not row count — failover multiplies attempts.
- 429 BALANCE vs RATE split is right; missing Retry-After → default cooldown acceptable v1.

**Top 5 concrete edits**

1. Drop the in-process-lock sentence; describe single-flight as advisory-lock only.
2. Replace "ok valid 7 days" with "ok never shipped to gateways; re-probe 3d (1h if input_shape) per A.4."
3. Add: "gun TTFB ≤ 60s; 240s ceiling derives from idle_timeout 300_000 − TTFB."
4. Add: input_shape healing uses a different probe shape; N=3 persistent cycles → promote to deny.
